# Ritik Agrawal

Open source application demos in TypeScript, React, Node.js, and SQLite.

## Projects

- [Taskboard](https://github.com/ritikagrawal1992-a11y/taskboard) — An issue tracker with persisted task states and priorities.
- [Stockroom](https://github.com/ritikagrawal1992-a11y/stockroom) — Transactional inventory adjustments with movement audit logs.
- [Roomwise](https://github.com/ritikagrawal1992-a11y/roomwise) — Resource booking with overlap checks and UTC timestamps.
- [Fairshare](https://github.com/ritikagrawal1992-a11y/fairshare) — Group expense splitting with exact cents and settlement suggestions.
- [Hookbox](https://github.com/ritikagrawal1992-a11y/hookbox) — Local signed webhook capture with idempotent event ingestion.
- [Findnote](https://github.com/ritikagrawal1992-a11y/findnote) — A searchable document library with ranked SQLite FTS5 prefix retrieval.

These projects were created in October 2026 with AI assistance. Each repository includes source code, a documented workflow, automated checks, and contribution notes.

I am building and reviewing this portfolio through practical improvements and regression tests. See individual repository histories for actual contributions.
